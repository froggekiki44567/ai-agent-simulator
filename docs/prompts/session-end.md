# Session end prompt

Use this at the end of every AI coding session.

---

1. Tick off completed tasks in PROJECT_PLAN.md (`- [x]`).
2. Update docs/progress.md: what's done, what's left, blockers.
3. Write docs/handoff/<your-name>.md: what you did, where you stopped, what comes next, what you need from the other person.
4. Suggest a commit message: `feat(agents): ...` / `fix(world): ...` / `docs: ...`
5. Run `dotnet build` and `dotnet test` before committing.
